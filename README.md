## Working with solutions

Solutions are grouped by topic so that related patterns are easier to revisit. Filenames identify the problem or exercise where practical.

For a local solution, compile the relevant C++ file with a C++17-compatible compiler. For example:

```bash
g++ -std=c++17 solution.cpp -o solution
./solution
```

Replace `solution.cpp` with the file you want to run. Some LeetCode submissions rely on the platform's supplied class or function signature and may need a small local test harness to compile independently.
